# NEVIO · План монетизации (задача 5) — отложено, не реализовано

> Статус: **план**. Код монетизации в проекте отсутствует — по решению владельца
> к оплате возвращаемся только после того, как стабильно работают базовые функции
> (мультистрановая архитектура, доверие/точность, прогресс, режим учителя).
> Прежняя реализация Telegram Stars была удалена из проекта, т.к. не работала.

## Требования к будущему решению

1. **Одинаково работает** в Telegram Mini App и на обычном сайте (одна логика).
2. **Учитывает разные страны СНГ**: цены/налог в местной валюте или универсальные
   цены, оплата картами РФ/КЗ/УЗ/РБ, без блокировок по региону.
3. **Не нарушает правило «100% бесплатно для владельца»**: на старте — только
   тарифы процессингов с 0 фиксированной платой (комиссия с оборота).

## Варианты (сравнение)

| Способ | Telegram | Сайт | Страны СНГ | Стоимость для владельца |
|---|---|---|---|---|
| Telegram Stars (повторно, после отладки) | ✅ нативно | ❌ | ✅ вся аудитория Telegram | 0 фикс., комиссия Telegram |
| Stripe | ❌ | ✅ | частично (не для РФ/РБ) | 0 фикс., ~2.9% + $0.30 |
| ЮKassa / CloudPayments | ❌ | ✅ | РФ (карты РФ) | 0 фикс. (у ЮKassa), комиссия |
| Robokassa / Prodamus | ❌ | ✅ | РФ + часть СНГ | 0 фикс., комиссия |
| Payme / Click (Узбекистан), Kaspi (Казахстан) | ❌ | ✅ | локальные рынки | 0 фикс., комиссия |
| CryptoCloud / бесплатные крипто-шлюзы | частично | ✅ | весь СНГ | 0 фикс., комиссия |

## Рекомендуемая архитектура (когда дойдём)

1. **Абстракция платежа** в коде: `PAYMENT_PROVIDERS = { telegramStars: {...}, card: {...} }`
   + выбор провайдера по платформе и стране пользователя (страна уже есть в `state.country`).
2. **Telegram Stars для мини-аппа** — заново и с тестами на реальном боте
   (sendInvoice + `pre_checkout_query` + `successful_payment`), с fallback-сообщением
   «оплата недоступна, откройте сайт» при сбое.
3. **Карты на сайте** — один бесплатный шлюз с поддержкой СНГ (старт с ЮKassa или
   Robokassa для РФ + рекуррентный вопрос по РБ/КЗ/УЗ по мере спроса).
4. **Продуктовые пакеты** (одинаковые во всех странах, цены локализованы):
   - Free: всё текущее (лимиты бесплатных моделей);
   - Pro: приоритетная очередь, длиннее контекст, больше генераций в день;
   - Школа/учитель: подписка на аналитику класса и синхронизацию сверх бесплатного.
5. **Проверки перед запуском**: рабочий бот с включёнными Stars, юридические
   документы (`terms.html`/`privacy.html` → раздел «Платные услуги»), учёт
   возрастной аудитории (платёж — только через родителя в Telegram / счёт на сайте).

**Что НЕ делать:** не добавлять платные ИИ-модели или платный бэкенд «ради
монетизации» — это нарушает правило бесплатной эксплуатации проекта.
