# NEVIO · Чек-лист ручного тестирования (реальный Telegram + сайт)

Автоматические прогоны (jsdom + Chromium/Playwright) покрывают все сценарии,
но финальную приёмку нужно пройти на реальных устройствах. Ниже — минимальный
сценарий для проверки перед показом пользователям.

## A. Первый запуск и выбор страны (4 страны)

1. Откройте бота в Telegram со свежего устройства/после очистки данных
   (в боте: «Удалить аккаунт» в настройках, либо новый Telegram-аккаунт).
2. Язык Telegram = русский → приложение должно открыть выбор страны
   (4 карточки) или сразу выбор роли с Беларусью (если данные уже были).
3. Язык Telegram = казахский → сразу Казахстан, интерфейс на казахском.
4. Язык Telegram = узбекский → сразу Узбекистан, интерфейс на узбекском.
5. Выбор страны вручную: Настройки → «Страна и язык» → карточки BY/RU/KZ/UZ.
6. Проверить, что у каждой страны своё меню: BY — ЦТ/ЦЭ; RU — ЕГЭ/ОГЭ;
   KZ — ЕНТ; UZ — вступительные тесты.

## B. Казахский и узбекский интерфейс

1. KZ → переключите язык на қазақша (Настройки → Язык интерфейса).
2. Пройдите: главное меню, настройки, настройку теста (предметы, количество,
   сложность), результат теста, прогресс, задания от учителя, режим учителя.
3. Нигде не должно оставаться русского текста интерфейса. Исключение
   (сознательное): статичное содержимое справки «Формат и критерии»
   (структура/критерии/советы) и содержимое самих ИИ-ответов — они на русском;
   перевод содержимого — отдельный этап по запросу.
4. Повторить для UZ/узбекского.

## C. Полный цикл учителя со вторым учеником

1. Учитель (Telegram): Режим учителя → «Мои классы» → создать класс «9А»,
   скопировать код.
2. «Задание классу» → тема (например, «Квадратные уравнения») →
   «Сгенерировать вопросы (ИИ)» → предпросмотр → «Сохранить и назначить».
3. Второй ученик (другой аккаунт/устройство, роль Ученик):
   Учёба → «Задания от учителя» → ввести код → решить все вопросы →
   «Завершить и отправить».
4. Учитель: «Аналитика класса» → выбрать задание → виден результат ученика,
   % верных по вопросам, типичные ошибки.
5. Без подключения Firebase шаги 3–4 работают на одном устройстве
   («Пробное прохождение» у учителя). Для разных устройств — вписать URL
   Firebase (бесплатный Spark) в `TEACHER_FIREBASE_DB` в `index.html`
   и повторить п. 1–4.

## D. ИИ-ответы и доверие

1. «Решить задачу» (любая страна) → в конце ответа должны быть рамки
   «📚 Опора на программу» и «🧮 Оценка по критериям».
2. «Проверка решения по критериям»: условие + решение с ошибкой →
   NEVIO должен указать шаг ошибки и балл по критериям экзамена страны.
3. «Формат и критерии» → статичная справка открывается мгновенно
   (без запроса к ИИ).

## E. Юридические страницы

1. Открыть privacy.html и terms.html на сайте → страна подхватывается из
   настроек приложения; переключатель BY/RU/KZ/UZ меняет блоки юрисдикций.
2. В BotFather: `/setprivacypolicy` → URL privacy.html, `/settermsofservice`
   → URL terms.html (см. README).

## F. Устойчивость к недоступности моделей

1. Временно закомментировать `OPENROUTER_MODELS` (оставить одну заведомо
   несуществующую модель) → приложение должно перейти на Groq/фолбэки или
   показать сообщение «Все модели временно недоступны» — без зависания.
2. Вернуть список обратно.

## G. Вёрстка на kk/uz

На устройствах 320–430px шириной проверить: главное меню, нижнюю навигацию,
настройки, настройку теста, страницу учителя — нет обрезанных слов и
горизонтальной прокрутки; последний пункт меню доскроливается выше нижней
навигации. (Автоматический поэлементный аудит этих экранов уже пройден.)
