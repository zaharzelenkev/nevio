# Скриншоты браузерной проверки (Chromium 149, headless)

Сняты при ручном прогоне сценариев (Playwright + Chromium 149, viewport 390×844
мобильный / 1280×900 десктоп). Сеть песочницы блокирует CDN Font Awesome и
Google Fonts, поэтому **иконки и фирменный шрифт на скриншотах отсутствуют**
(шрифт — системный DejaVu); в реальном окружении иконки/Inter загружаются
штатно. На вёрстку текста это влияния не оказывает.
