## 🎯 Что это?

**NEVIO** — автономное веб-приложение и Telegram Mini App (один файл — одна логика)
для учащихся и педагогов Беларуси, России, Казахстана и Узбекистана.
Работает без серверов, использует только бесплатные модели ИИ с авто-резервированием
и чередованием провайдеров (OpenRouter `:free` + Groq free tier).

## 🌍 Страны и экзамены

Страна определяется при первом запуске (язык Telegram → подсказка по геолокации →
ручной выбор) и меняется в «Настройки → Страна и язык». Для каждой страны —
своя программа, формат экзамена, критерии оценивания и статичная база знаний:

| Страна | Экзамены | Языки интерфейса |
|---|---|---|
| 🇧🇾 Беларусь | ЦТ/ЦЭ, экзамены после 9 класса | Русский |
| 🇷🇺 Россия | ЕГЭ, ОГЭ | Русский |
| 🇰🇿 Казахстан | ЕНТ, итоговые экзамены после 9 класса | Русский, Қазақша |
| 🇺🇿 Узбекистан | Вступительные тесты (189 баллов), выпускные после 9 класса | Русский, Oʻzbekcha |

Белорусская версия осталась полностью рабочей и не изменилась в поведении —
это одна из полноценных страна-конфигураций. Подробности: [docs/MULTICOUNTRY.md](docs/MULTICOUNTRY.md).

## 🔍 Точность и доверие («почему это верно»)

При решении задач и объяснении тем NEVIO не просто выдаёт ответ:

- **«📚 Опора на программу»** — конкретные правила из статичной базы правил страны
  с указанием раздела программы/кодификатора (ЦТ, ЕГЭ, ЕНТ, тесты Узбекистана);
- **«🧮 Оценка по критериям»** — как решение оценивается по критериям экзамена
  страны: за что полный балл, где теряются баллы;
- действие **«Проверка решения по критериям»** — проверка решения ученика по шагам
  с балльной оценкой по критериям экзамена.

Базы правил, структура экзаменов и критерии — статичные тексты в коде:
ответы точнее и не тратят бесплатные квоты запросов к моделям.

## 📈 Прогресс и персональные рекомендации

- История тем/заданий и тип ошибок сохраняются локально (вкладка «Прогресс»).
- Дашборд: точность, тесты, вопросы, полосы по предметам.
- Слабые места вычисляются автоматически («слабое место — тригонометрия»),
  по ним генерируются рекомендации: 5 заданий по теме, объяснение, тест по предмету.

## 👩‍🏫 Режим учителя: классы и аналитика

Поверх существующих учительских функций (планы уроков, генератор заданий,
варианты A/B) добавлен блок «Класс и аналитика»:

- классы с кодом доступа; задания классу (вопросы генерируются ИИ один раз);
- ученики присоединяются по коду и решают на своей стороне;
- агрегированная аналитика: кто справился, средний результат, % верных ответов
  по каждому вопросу, типичные ошибки группы.

**Работает полностью без серверов:** учитель копирует «код задания» (NEV1…),
в котором зашиты все вопросы, и отправляет ученикам; ученик вставляет его
в «Задания от учителя» — задание открывается даже без интернета. Ученик после
решения копирует «код результата» (NEVR1…) и присылает учителю, учитель вносит
его в аналитику в один клик. Никаких платных сервисов и настроек не требуется.

Опционально (для автоматической передачи результатов) можно вписать URL
бесплатной **Firebase Realtime Database (тариф Spark — бесплатный навсегда,
без банковской карты)** в константу `TEACHER_FIREBASE_DB` в `index.html`
(см. docs/MULTICOUNTRY.md). Коды при этом продолжают работать.

## ✨ Ключевые особенности

### 📐 Красивые математические формулы
NEVIO использует **MathJax 3** для рендеринга LaTeX-формул прямо в ответах:
- Квадратные уравнения: $D = b^2 - 4ac$
- Интегралы: $\int_a^b f(x)dx$
- Тригонометрия: $\sin^2 x + \cos^2 x = 1$
- И многое другое!

### 🎓 Режимы работы

#### 🎒 Для учеников:
- **Подготовка к ЦТ/ЦЭ** — структурированная подготовка по всем предметам
- **Интерактивный тест** — генерация тестов с объяснениями
- **Книга формул** — все формулы с LaTeX-рендерингом
- **Решение задач** — пошаговые объяснения
- **Конспекты и схемы** — визуальные материалы

#### 👩‍🏫 Для учителей:
- Планы уроков
- Генератор заданий и контрольных
- Дифференцированный подход

### 🔄 Авто-резервирование и чередование провайдеров
```
Запрос → ротация стартового провайдера (по кругу):
├── OpenRouter (только бесплатные модели):
│   ├── openrouter/free                        ← роутер по бесплатным моделям
│   ├── google/gemma-4-31b-it:free
│   ├── google/gemma-4-26b-a4b-it:free
│   ├── nvidia/nemotron-3-super-120b-a12b:free
│   └── openai/gpt-oss-20b:free
└── Groq free tier (если вписан бесплатный GROQ_API_KEY):
    ├── llama-3.3-70b-versatile
    └── llama-3.1-8b-instant
```
При недоступности модели/лимите — автоматическое переключение на следующую
модель и следующего провайдера. Чередование делит нагрузку между бесплатными
квотами OpenRouter и Groq. Без ключа Groq поведение ровно прежнее (только OpenRouter).

> ⚠️ Не используйте `openrouter/auto`: этот роутер выбирает модель в том числе
> из платных и тарифицируется по цене выбранной модели. Суффикс `:free` на роутер
> не действует — `openrouter/auto:free` тоже платный. Для нулевой стоимости
> используйте `openrouter/free` или конкретные модели с суффиксом `:free`.

## ⚙️ Необязательные настройки (бесплатные)

В `index.html` есть две константы-переключателя (по умолчанию выключены —
ничего не меняют):

- `GROQ_API_KEY` — бесплатный ключ [console.groq.com](https://console.groq.com):
  включает второй провайдер ИИ и чередование нагрузки с OpenRouter.
- `TEACHER_FIREBASE_DB` — URL базы Firebase Realtime Database (тариф Spark,
  бесплатный): включает синхронизацию заданий и аналитики класса между
  устройствами. Правила БД — в docs/MULTICOUNTRY.md.

## 📄 Политика конфиденциальности и условия использования

Документы покрывают все четыре страны (BY/RU/KZ/UZ): общий текст + блоки по
юрисдикциям (правовые основания, права субъектов данных, официальные ресурсы,
применимое право). Страна подхватывается из настроек приложения, на странице
есть переключатель страны. Раскрыты ipapi.co (подсказка страны по IP, не чаще
раза в сутки) и опциональная Firebase-синхронизация режима учителя.

Документы доступны пользователям двумя способами:
1. **В приложении** — раздел «Настройки» → «Политика конфиденциальности» и «Условия использования».
2. **Как отдельные страницы** — `privacy.html` и `terms.html` (в том же стиле, что и приложение).

**Важно перед запуском:**
1. Замените контактный адрес `support@nevio.app` на свой реальный e-mail во всех трёх местах: внутри приложения (`index.html`, разделы «Политика» и «Условия»), а также в `privacy.html` и `terms.html`.
2. Загрузите `privacy.html` и `terms.html` на хостинг вместе с `index.html`.

**Как подключить к боту в Telegram (BotFather):**
1. Откройте @BotFather → ваш бот.
2. Задайте боту политику конфиденциальности: `/setprivacypolicy` → укажите ссылку, например `https://ваш-сайт/privacy.html`.
3. Задайте условия использования: `/settermsofservice` → `https://ваш-сайт/terms.html`.
4. Если этих команд нет в вашей версии BotFather, добавьте ссылки на документы в описание бота: `/setdescription` → «Политика конфиденциальности: https://ваш-сайт/privacy.html · Условия: https://ваш-сайт/terms.html».

Telegram требует, чтобы боты и мини-приложения, которые обрабатывают данные пользователей, имели публичную политику конфиденциальности — после подключения ссылок требования платформы будут выполнены.

## 🖼 Как поменять логотип (фавиконку)

Сейчас в проекте стоит заглушка: золотой квадрат с буквой **N**.

**Важно:** для браузера и Google достаточно одного файла `favicon.png`.
Остальные (`favicon.ico`, `apple-touch-icon.png`, `android-chrome-*`) нужны,
чтобы тот же логотип корректно показывался на iPhone/Android при добавлении
на главный экран и в старых браузерах. Их можно сгенерировать из одного
файла автоматически.

**Способ 1 — одной командой (Linux/macOS, есть ImageMagick):**
1. Положите свой логотип в папку проекта как `logo.png` (PNG, лучше квадрат 512×512).
2. Запустите:
   ```bash
   bash make-icons.sh logo.png
   ```
3. Скрипт сам создаст `favicon.png`, `favicon.ico`, `apple-touch-icon.png`,
   `android-chrome-192.png`, `android-chrome-512.png`.
4. Загрузите все файлы на хостинг **в ту же папку, где лежит `index.html`**.

**Способ 2 — через генератор (для Windows/без установки):**
1. Зайдите на [realfavicongenerator.net](https://realfavicongenerator.net) или [favicon.io](https://favicon.io).
2. Загрузите свой логотип — генератор выдаст все файлы и готовый HTML.
3. Замените файлы в проекте и обновите ссылки `<link rel="icon">` в `index.html`, если генератор дал другие имена.

**Если не нужны иконки для телефонов** — можно оставить только `favicon.png`
и удалить лишние файлы со ссылками из `index.html`; на браузер и Google это не повлияет.

**Как логотип появится в Google:**
- Google берёт фавиконку из `/favicon.ico` или из `<link rel="icon">` — ссылки уже прописаны в `index.html`.
- Убедитесь, что файлы загружены на хостинг: откройте в браузере `https://ваш-сайт/favicon.png` — картинка должна открыться.
- В [Google Search Console](https://search.google.com/search-console) откройте «Проверка URL» → «Запросить индексирование» для главной страницы.
- После переиндексации (обычно от нескольких дней до пары недель) значок появится рядом с сайтом в результатах поиска.
- В вкладке браузера и при добавлении на главный экран телефона иконка появится сразу после загрузки файлов на хостинг.

**Один файл — вся логика!** Это упрощает проверку и демонстрацию на конкурсе.
