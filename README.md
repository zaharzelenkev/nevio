**NEVIO** — это современное веб-приложение и Telegram Mini App, созданное для помощи учащимся, учителям и воспитателям в образовательном процессе Республики Беларусь. Приложение объединяет мощь современных больших языковых моделей (LLM) со встроенной базой знаний по ЦТ/ЦЭ и учебным программам.

## 🏗 Архитектура проекта и почему выбрана эта связка

Для обеспечения максимальной скорости, бесплатной работы и безопасности в конкурсном проекте используется следующая архитектура:

```
[ Telegram Mini App / Web Browser (index.html) ]
                       │
                       ▼  POST { messages, model, stream }
     [ Cloudflare Worker Proxy (worker.js) ]  <─── Хранит OPENROUTER_API_KEY в секретах
                       │
                       ▼  CORS + Smart Failover Loop
        [ OpenRouter AI (Бесплатные модели) ]
   (Llama 3.3 70B, GPT-OSS 120B, Nemotron, Qwen 3)
```

### Преимущества архитектуры для оценки жюри:
1. **Нулевая стоимость владения (Free Tier)**:
   - **Cloudflare Workers** предоставляет **100 000 бесплатных запросов в день** навсегда без привязки банковской карты.
   - **OpenRouter (`:free`)** предоставляет бесплатные лимиты к топ-моделям с открытым исходным кодом.
2. **Безопасность API-ключа**:
   - Ключ OpenRouter хранится в защищённых секретных переменных Cloudflare (`OPENROUTER_API_KEY`) и **не раскрывается** в клиентском JavaScript-коде.
3. **Автоматическое резервирование моделей (Smart Failover)**:
   - Если основная бесплатная модель испытывает высокую нагрузку (ошибки `404` или `429`), воркер автоматически переключается на следующую доступную модель в течение миллисекунд.
   - Никаких сбоев перед жюри или пользователями во время демонстрации!
4. **Легковесный фронтенд (0 зависимостей)**:
   - Чистый Vanilla JS / HTML5 / CSS3, работающий мгновенно даже на мобильных устройствах.

## 🚀 Пошаговая инструкция: Подключение Cloudflare Workers бесплатно за 5 минут

Чтобы ваш проект был идеальным с точки зрения безопасности и архитектуры, выполните эти 5 простых шагов для деплоя прокси-сервера:

### Шаг 1. Регистрация в Cloudflare (без банковской карты)
1. Перейдите на официальный сайт: [https://dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up).
2. Зарегистрируйтесь с вашим email (или войдите в существующий аккаунт). Привязывать карту **не требуется**.

### Шаг 2. Создание Worker
1. В панели управления слева выберите **Workers & Pages** → **Overview**.
2. Нажмите кнопку **Create application** (Создать приложение), затем **Create Worker** (Создать Worker).
3. Укажите любое имя воркера, например `nevio-proxy`, и нажмите **Deploy** (Опубликовать).

### Шаг 3. Добавление кода из `worker.js`
1. После успешного создания нажмите **Edit code** (Редактировать код).
2. В открывшемся редакторе **полностью замените** стандартный код на содержимое файла [`worker.js`](./worker.js) из этого репозитория.
3. Нажмите кнопку **Deploy** в правом верхнем углу, чтобы сохранить изменения.

### Шаг 4. Настройка секретного API-ключа (`OPENROUTER_API_KEY`)
1. Вернитесь на страницу вашего воркера в панели Cloudflare: выберите вкладку **Settings** (Настройки) → **Variables and Secrets** (Переменные и секреты).
2. В разделе **Secrets** нажмите **Add**:
   - **Type**: `Secret` (Зашифрованный секрет)
   - **Name**: `OPENROUTER_API_KEY`
   - **Value**: Вставьте ваш API-ключ, полученный на сайте [https://openrouter.ai/keys](https://openrouter.ai/keys) (начинается с `sk-or-v1-...`).
3. Нажмите **Deploy** / **Save** для сохранения секрета.
   > *Примечание*: Бесплатные ключи OpenRouter не требуют оплаты и дают доступ к моделям с суффиксом `:free`.

### Шаг 5. Подключение URL воркера к `index.html`
1. На странице вашего воркера скопируйте его адрес (URL вида `https://nevio-proxy.ваш_логин.workers.dev`).
2. Откройте файл `index.html` и в строке с настройками укажите ваш URL:
   ```javascript
   const API_PROXY_URL = "https://nevio-proxy.username.workers.dev";
   const OPENROUTER_API_KEY = ""; // Ключ теперь можно оставить пустым, он в Cloudflare!
   ```
3. Готово! Теперь ваш проект полностью защищён и готов к демонстрации на конкурсе.

## 💡 Режимы работы в `index.html`

Приложение поддерживает два режима работы без изменения остального кода:

1. **Серверный прокси (Cloudflare Worker)** — *рекомендуемый режим для конкурса*:
   ```javascript
   const API_PROXY_URL = "https://nevio-proxy.username.workers.dev";
   const OPENROUTER_API_KEY = "";
   ```
2. **Прямой запрос (Browser Direct)** — *режим для быстрого локального тестирования*:
   ```javascript
   const API_PROXY_URL = "";
   const OPENROUTER_API_KEY = "sk-or-v1-ваш-ключ-здесь";
   ```

## 💻 Запуск проекта локально

Для тестирования локально на компьютере достаточно открыть `index.html` в браузере или запустить простой HTTP-сервер:

```bash
# С использованием Python
python3 -m http.server 8000

# С использованием Node.js (npx)
npx serve .
```

После этого откройте [http://localhost:8000](http://localhost:8000) в браузере.
