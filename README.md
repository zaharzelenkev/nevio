## 🎯 Что это?

**NEVIO** — автономное веб-приложение и Telegram Mini App для поддержки учащихся и педагогов Беларуси. Работает без серверов, использует бесплатные модели ИИ с авто-резервированием.

## ✨ Ключевые особенности

### 📐 Красивые математические формулы
NEVIO использует **MathJax 3** для рендеринга LaTeX-формул прямо в ответах:
- Квадратные уравнения: $D = b^2 - 4ac$
- Интегралы: $\int_a^b f(x)dx$
- Тригонометрия: $\sin^2 x + \cos^2 x = 1$
- И многое другое!

#### 🎒 Для учеников:

### 🔄 Авто-резервирование моделей
```
OpenRouter (бесплатные модели):
├── openrouter/auto
├── meta-llama/llama-3.3-70b-instruct:free
├── qwen/qwen3-30b-a3b:free
├── nvidia/nemotron-4-340b-instruct:free
└── deepseek/deepseek-prover-v2:free
```
При недоступности одной модели — автоматическое переключение на следующую.

## 🚀 Запуск

### Вариант 1: Telegram Mini App
1. Откройте @BotFather в Telegram
2. Создайте нового бота
3. Настройте WebApp
4. Загрузите index.html на хостинг
5. Укажите URL в настройках бота

### Вариант 2: Локальный запуск
```bash
# Просто откройте index.html в браузере
open index.html
# Или используйте Python
python -m http.server 8000
```

### Вариант 3: GitHub Pages
1. Forkните репозиторий
2. Включите GitHub Pages
3. Готово!

## 🔧 Технологии

- **HTML5 / CSS3 / JavaScript** — Vanilla JS, никаких фреймворков
- **MathJax 3** — рендеринг LaTeX формул
- **Font Awesome 6** — иконки
- **Google Fonts** — шрифты Abril Fatface + Inter
- **OpenRouter API** — доступ к LLM моделям
- **Telegram WebApp API** — интеграция с Telegram

## 📊 Статистика использования

Приложение отслеживает:
- Количество запросов
- Пройденных тестов
- Дней использования

## 🔒 Конфиденциальность

- Все данные хранятся локально (`localStorage`)
- Запросы идут напрямую в OpenRouter
- Никаких сторонних серверов
- Telegram данные используются только для аватарки
