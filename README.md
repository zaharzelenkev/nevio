**NEVIO** — это автономное веб-приложение и Telegram Mini App, созданное для всесторонней поддержки учащихся, абитуриентов, учителей и воспитателей Республики Беларусь. Приложение работает без промежуточных серверов и сложного бэкенда, используя мощь современных больших языковых моделей (LLM) со встроенной базой знаний по ЦТ/ЦЭ и учебным программам.

---

## 🌟 Ключевые возможности и роли

### 1. 🎓 Ученик (Абитуриент / Школьник)
- **Подготовка к ЦТ / ЦЭ**: актуальная структура тестов (Математика, Физика, Химия, Биология, История Беларуси, языки).
- **Экзамен 9 класса**: помощь в подготовке к выпускным экзаменам.
- **Генератор тестов ЦТ**: автоматическое создание тренировочных тестов формата ЦТ/ЦЭ с проверкой и пояснениями.
- **Решение и объяснение задач**: подробные разборы задач и тем простым языком.
- **Конспекты, схемы и анализ произведений**: быстрая подготовка к урокам литературы и другим предметам.

### 2. 👩‍🏫 Учитель
- **Планирование уроков**: составление подробных планов занятий по стандартам образования.
- **Генерация контрольных и тестовых вариантов**: создание разноуровневых заданий (дифференциация).
- **Анализ текстов и вопросы**: генерация вопросов по чтению или изучаемому материалу.

## 🏗 Автономная архитектура (0 серверов, 0 бэкенда)

Приложение спроектировано для максимального удобства проверки и демонстрации на конкурсе:

```
[ Telegram Mini App / Web Browser (index.html) ]
                       │
                       ▼  Прямой вызов с авто-резервированием (Smart Failover)
        [ OpenRouter AI (Бесплатные модели) ]
   ├── openrouter/free
   ├── meta-llama/llama-3.3-70b-instruct:free
   ├── openai/gpt-oss-120b:free
   ├── nvidia/nemotron-3-ultra-550b-a55b:free
   └── qwen/qwen3-next-80b-a3b-instruct:free
```

### Преимущества архитектуры для жюри и пользователей:
1. **Мгновенный запуск без серверов (Zero DevOps)**:
   - Не требуется разворачивать бэкенд, базы данных или облачные сервисы.
   - Можно открыть файл `index.html` в браузере или разместить его на любом бесплатном статическом хостинге (GitHub Pages, Telegram WebApp, Netlify, Vercel).
2. **Интеллектуальное авто-резервирование моделей (Smart Failover)**:
   - В функцию запроса встроена проверка статуса сети и нагрузки на модели ИИ.
   - Если одна из бесплатных моделей отвечает кодом `404` (модель недоступна) или `429` (лимит запросов), приложение автоматически и прозрачно для пользователя переключается на следующую доступную модель.
3. **Отсутствие внешних зависимостей (Vanilla JS + HTML5 + CSS3)**:
   - Приложение состоит из одного файла `index.html` без сборщиков (Webpack/Vite) и тяжелых библиотек.
   - Загружается менее чем за 1 секунду даже при слабом мобильном интернете.
