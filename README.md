## 🎯 Что это?

**NEVIO** — автономное веб-приложение и Telegram Mini App для поддержки учащихся и педагогов Беларуси. Работает без серверов, использует бесплатные модели ИИ с авто-резервированием.

## ✨ Ключевые особенности

### 📐 Красивые математические формулы
NEVIO использует **MathJax 3** для рендеринга LaTeX-формул прямо в ответах:
- Квадратные уравнения: $D = b^2 - 4ac$
- Интегралы: $\int_a^b f(x)dx$
- Тригонометрия: $\sin^2 x + \cos^2 x = 1$
- И многое другое!

## 🖼 Как поменять логотип (фавиконку)

Сейчас в проекте стоит заглушка: золотой квадрат с буквой **N**.

**Быстрый способ** — замените готовые файлы, не меняя названия:

1. Подготовьте логотип в PNG 512×512 (квадрат, желательно с прозрачным фоном).
2. Перезапишите им `favicon.png`.
3. Сконвертируйте его в `favicon.ico` (16/32/48 px) — например, на [favicon.io](https://favicon.io) или в любом редакторе.
4. Загрузите все файлы на хостинг **в ту же папку, где лежит `index.html`**.

**Правильный способ** — отредактируйте `logo-nevio.svg` (вектор, любой текстовый редактор),
затем сконвертируйте его в PNG/ICO и обновите остальные файлы:
```bash
# если есть ImageMagick / rsvg-convert
convert logo-nevio.svg -resize 512x512 favicon.png
convert logo-nevio.svg -resize 180x180 apple-touch-icon.png
convert favicon.png -define icon:auto-resize=16,32,48 favicon.ico
```

**Как логотип появится в Google:**
- Google берёт фавиконку из `/favicon.ico` или из `<link rel="icon">` — ссылки уже прописаны в `index.html`.
- Убедитесь, что файлы загружены на хостинг: откройте в браузере `https://ваш-сайт/favicon.ico` — картинка должна открыться.
- В [Google Search Console](https://search.google.com/search-console) откройте «Проверка URL» → «Запросить индексирование» для главной страницы.
- После переиндексации (обычно от нескольких дней до пары недель) значок появится рядом с сайтом в результатах поиска.
- В вкладке браузера и при добавлении на главный экран телефона иконка появится сразу после загрузки файлов на хостинг.

**Один файл — вся логика!** Это упрощает проверку и демонстрацию на конкурсе.
